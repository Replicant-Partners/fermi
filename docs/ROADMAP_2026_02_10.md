# Roadmap — 2026-02-10

## Where We Are

27 agents, 17 tools, 122 routes, full execution pipeline with agentic tool loops, coherence system, eval framework, workspaces with git-backed files, MCP server for Zed. The platform runs. The question is: does it *work* end-to-end when a real user sits down?

## Immediate Next (This Week)

### 1. Workspace Stress Test
**Goal**: Walk through the full workspace lifecycle and find what breaks.
- Create workspace, hire 3-4 agents, chat, invoke tools, check coherence
- Test compound agent execution (social_media_studio with sub-agents)
- Test image generation + workspace file writing
- Verify gas deduction at every step
- Document any failures → fix them

### 2. Embedding Generation in Execute Pipeline
**Goal**: Episodes should have embeddings, not `None`.
- Wire EmbeddingGenerator call after episode storage in execute_agent_handler
- This unblocks: semantic search (search_knowledge tool), projector (real data), consolidation quality
- Single insertion point in api_server.rs execute pipeline

### 3. Consolidation Trigger
**Goal**: `POST /api/agents/:id/consolidate` — run dreaming on demand.
- Endpoint already designed, just needs wiring
- Allows testing the full AKP loop: execute → episodes → consolidate → rules → ontology
