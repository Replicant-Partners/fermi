# Agent Bestiary Go-To-Market Plan

**Last Updated**: February 7, 2026

## Overview

Agent Bestiary is a universal Active Dreaming Memory (ADM) backend for AI agents. This GTM plan outlines our strategy to launch and scale the product from 0 to first 100 users.

**Target Launch**: Q2 2026 (April-May)

## Core Value Proposition

"Real memory for AI agents - episodic to semantic consolidation that actually works"

## Key Differentiators

1. **GDPR-compliant by design** - Per-agent git repositories enable complete data deletion
2. **GitHub as source of truth** - All agent learning is transparent and auditable
3. **Framework-agnostic** - Works with LangChain, AutoGPT, CrewAI, or custom agents
4. **Production-ready** - PostgreSQL + pgvector with enterprise-grade reliability
5. **Open ontology format** - No vendor lock-in, exportable knowledge graphs

## Target Customer Segments

### Primary (Launch Focus)
- **AI Agent Framework Developers** - LangChain, AutoGPT, CrewAI maintainers
- **AI Startups Building Agents** - Companies building AI assistants/copilots
- **AI Research Labs** - Academic researchers studying agent memory

### Secondary (Post-Launch)
- **Enterprise AI Teams** - Large companies deploying internal agents
- **AI Consultancies** - Agencies building agents for clients
